# Game compatibility — MotionPad v1.0

## Confirmed working on real PS2 hardware

- ✅ Gran Turismo 3
- ✅ Gran Turismo 4
- ✅ Gran Turismo 4 Spec II
- ✅ Tourist Trophy
- ✅ Need for Speed: Carbon

The above results come from project hardware testing, not a comprehensive compatibility survey. A game not shown above is **untested**, not automatically unsupported.

## Community test reports

Please open a **Game compatibility report** issue, including:

- Game name, region and disc/game ID (if available)
- Real PS2 model or PCSX2 version
- USB connection/tethering details
- Whether the game launches, responds to steering, throttle, and brake
- Whether analog sticks, face buttons, and other inputs behave correctly
- Any reproducible lag, mapping problems, or crashes

Do not upload game ISOs, firmware, BIOS images, or copyrighted game assets.

## What this repository tracks

Compatibility results will be reviewed and added after reproducible testing or sufficiently detailed independent reports. Please distinguish *reported by a tester* from *verified by the maintainer*.
